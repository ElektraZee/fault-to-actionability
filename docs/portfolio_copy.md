# Portfolio Website Copy

## Project title
Fault-to-Actionability: Manufacturing Problem-Solving Workflow

## Short description
A Streamlit portfolio prototype that tests the hypothesis that manufacturing organizations may have enough fault visibility but still lack a reliable process for converting repeated events into owned, verified countermeasures. The app uses synthetic data to connect repeat-fault analysis, recovery-time metrics, accountability, and problem closure.

## Skills demonstrated
Python, Streamlit, pandas, Plotly, manufacturing analytics, TPS problem solving, process mapping, requirements analysis, user stories, UAT, Git, GitHub, and cloud deployment.
