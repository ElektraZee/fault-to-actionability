# Business Requirements

| ID | Requirement |
|---|---|
| BR-001 | The system shall load synthetic fault events containing equipment, area, crew, fault code, severity, and timestamps. |
| BR-002 | The system shall calculate fault duration, restart delay, and total recovery time. |
| BR-003 | The system shall identify recurring equipment/fault-code pairs using a defined threshold. |
| BR-004 | The dashboard shall display recurring fault pairs, median recovery time, open problems, and overdue problems. |
| BR-005 | Users shall be able to filter fault events by equipment, crew, and fault code. |
| BR-006 | Users shall be able to download filtered events as CSV. |
| BR-007 | Users shall be able to assign an owner, priority, and due date to a problem. |
| BR-008 | Users shall be able to document containment, root cause, countermeasure, and effectiveness evidence. |
| BR-009 | The system shall guide problems through a defined status sequence. |
| BR-010 | The system shall prevent closure without effectiveness evidence. |
| BR-011 | Users shall be able to view fault events linked to a selected problem. |
| BR-012 | The app shall clearly disclose that all data and results are synthetic. |
