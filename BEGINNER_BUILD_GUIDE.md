# Beginner-friendly Build Guide

Use the step-by-step instructions in the accompanying ChatGPT response. This repository is a working reference structure so you can compare your files as you build.

Recommended order:
1. Install Python, Git, VS Code, and the VS Code Python extension.
2. Open this folder in VS Code.
3. Create a `.venv` virtual environment.
4. Install `requirements.txt`.
5. Run `python scripts/generate_demo_data.py`.
6. Run `python -m streamlit run streamlit_app.py`.
7. Complete the UAT table.
8. Initialize Git and push to GitHub.
9. Deploy from GitHub to Streamlit Community Cloud.
10. Add the live app and GitHub links to your portfolio website.
